# 关卡进度管理系统使用说明

## 概述

本系统实现了游戏关卡的本地进度存储功能，允许玩家从上次离开的关卡继续游戏。

## 核心组件

### 1. LevelProgressManager（关卡进度管理器）

**功能：**
- 管理游戏关卡的进度存储和读取
- 使用PlayerPrefs进行本地存储
- 跨场景持久化的单例模式

**主要方法：**
- `StartNewGame()` - 开始新游戏（重置所有进度）
- `ContinueGame()` - 继续游戏（从上次进度开始）
- `SetCurrentLevel(string levelName)` - 设置当前关卡
- `CompleteLevel(string levelName)` - 标记关卡为已完成
- `GetCurrentLevelToLoad()` - 获取当前应该加载的关卡
- `HasGameStarted()` - 检查游戏是否已开始过
- `GetProgressPercentage()` - 获取游戏进度百分比

### 2. StartMenuManager（开始菜单管理器）

**新增功能：**
- `OnStartNewGameClicked()` - 开始新游戏按钮事件
- `OnContinueGameClicked()` - 继续游戏按钮事件
- `HasGameProgress()` - 检查是否有游戏进度可以继续
- `GetProgressInfo()` - 获取游戏进度信息

### 3. GameFlowManager（游戏流程管理器）

**集成功能：**
- 在关卡完成时自动更新进度管理器
- 在进入下一关卡时设置当前关卡

## 使用方法

### 1. 在开始菜单中使用

在开始菜单场景中，需要设置两个按钮：

```csharp
// 开始新游戏按钮
public void OnStartNewGameButtonClick()
{
    StartMenuManager startMenu = FindObjectOfType<StartMenuManager>();
    if (startMenu != null)
    {
        startMenu.OnStartNewGameClicked();
    }
}

// 继续游戏按钮
public void OnContinueGameButtonClick()
{
    StartMenuManager startMenu = FindObjectOfType<StartMenuManager>();
    if (startMenu != null)
    {
        startMenu.OnContinueGameClicked();
    }
}
```

### 2. 检查游戏进度

```csharp
// 检查是否有进度可以继续
if (StartMenuManager startMenu = FindObjectOfType<StartMenuManager>())
{
    bool hasProgress = startMenu.HasGameProgress();
    if (hasProgress)
    {
        // 显示"继续游戏"按钮
        continueButton.SetActive(true);
    }
    else
    {
        // 只显示"开始新游戏"按钮
        continueButton.SetActive(false);
    }
}
```

### 3. 显示进度信息

```csharp
// 获取进度信息文本
string progressInfo = startMenu.GetProgressInfo();
// 输出示例：已完成 2/3 关卡 (67%)
```

## 关卡序列配置

关卡序列在 `PublicData.cs` 中定义：

```csharp
public static readonly string[] LevelSequence = { "level1", "level2", "level3" };
```

## 存储键名

系统使用以下PlayerPrefs键名：
- `CurrentLevel` - 当前关卡
- `CompletedLevels` - 已完成的关卡列表（逗号分隔）
- `GameStarted` - 游戏是否已开始标记

## 测试功能

使用 `LevelProgressTester` 脚本进行功能测试：

1. 将脚本添加到场景中的GameObject
2. 在Inspector中设置UI引用
3. 使用Context Menu进行测试：
   - 测试保存进度
   - 测试加载进度
   - 测试清除进度
   - 显示当前进度

## 工作流程

### 新游戏流程：
1. 玩家点击"开始新游戏"
2. 调用 `LevelProgressManager.StartNewGame()` 重置进度
3. 加载第一个关卡（level1）

### 继续游戏流程：
1. 玩家点击"继续游戏"
2. 调用 `LevelProgressManager.ContinueGame()`
3. 系统自动确定应该加载的关卡
4. 加载对应关卡

### 关卡完成流程：
1. 关卡完成时，`GameFlowManager.CompleteLevel()` 被调用
2. 自动更新 `LevelProgressManager` 中的完成状态
3. 进入结算页面

### 进入下一关卡流程：
1. 在结算页面点击"下一关"
2. `GameFlowManager.GoToNextLevel()` 被调用
3. 自动设置新的当前关卡
4. 加载下一关卡

## 注意事项

1. **单例模式**：`LevelProgressManager` 使用单例模式，确保跨场景持久化
2. **自动初始化**：各个关卡管理器会在Start()中自动设置当前关卡
3. **兼容性**：系统与现有的游戏流程完全兼容，不会影响原有功能
4. **调试功能**：所有关键操作都有详细的调试日志输出

## 扩展功能

如需添加更多关卡，只需：
1. 在 `PublicData.LevelSequence` 中添加新的关卡名称
2. 创建对应的关卡管理器脚本
3. 在关卡管理器的Start()方法中添加进度设置代码

## 故障排除

如果进度功能不工作，请检查：
1. `LevelProgressManager` 是否正确添加到场景中
2. 关卡管理器是否正确设置了当前关卡
3. 检查Console中的调试日志
4. 使用 `LevelProgressTester` 进行功能测试
