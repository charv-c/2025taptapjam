# 退出游戏弹窗按钮预制体系统使用说明

## 概述

ExitGameManager现在支持使用按钮预制体来自动创建和布局确认对话框的按钮，无需手动在场景中放置按钮。

## 核心功能

### 1. 预制体引用系统
- 使用预制体来创建确认和取消按钮
- 自动在Canvas中排布按钮
- 支持自定义按钮布局参数

### 2. 自动布局系统
- 自动创建按钮容器
- 使用HorizontalLayoutGroup进行水平布局
- 支持自定义按钮间距和大小

## 配置方法

### 方法一：Inspector设置（推荐）

1. **设置预制体引用**：
   - `Confirm Button Prefab` - 确认退出按钮预制体
   - `Cancel Button Prefab` - 取消退出按钮预制体

2. **配置布局参数**：
   - `Button Spacing` - 按钮间距（默认20f）
   - `Button Size` - 按钮大小（默认120x40）
   - `Auto Layout Buttons` - 是否自动布局（默认开启）

3. **设置基础UI**：
   - `Exit Button` - 触发退出确认的按钮
   - `Confirmation Dialog` - 确认对话框GameObject

### 方法二：代码设置

```csharp
// 获取ExitGameManager引用
ExitGameManager exitManager = FindObjectOfType<ExitGameManager>();

// 设置按钮预制体
GameObject confirmPrefab = Resources.Load<GameObject>("UI/ConfirmButton");
GameObject cancelPrefab = Resources.Load<GameObject>("UI/CancelButton");
exitManager.SetButtonPrefabs(confirmPrefab, cancelPrefab);

// 设置布局参数
exitManager.SetButtonLayout(30f, new Vector2(150f, 50f));
```

## 工作流程

### 1. 初始化阶段
1. ExitGameManager在Start()时调用SetupUI()
2. 自动调用CreateConfirmationButtons()
3. 查找Canvas并创建按钮容器
4. 实例化按钮预制体并设置事件

### 2. 按钮创建流程
1. **查找Canvas**：从确认对话框向上查找Canvas组件
2. **创建容器**：创建名为"ButtonContainer"的容器GameObject
3. **添加布局组件**：
   - HorizontalLayoutGroup - 水平布局
   - ContentSizeFitter - 自动调整大小
4. **实例化按钮**：从预制体创建确认和取消按钮
5. **设置事件**：自动绑定按钮点击事件
6. **应用布局**：设置按钮大小和间距

### 3. 用户交互流程
1. 用户点击退出按钮或按ESC键
2. 显示确认对话框（包含自动创建的按钮）
3. 用户点击确认或取消按钮
4. 执行相应操作并隐藏对话框

## 预制体要求

### 确认按钮预制体
- 必须包含Button组件
- 建议包含Text组件显示"确认"或"退出"
- 可以包含Image组件设置按钮外观

### 取消按钮预制体
- 必须包含Button组件
- 建议包含Text组件显示"取消"
- 可以包含Image组件设置按钮外观

### 预制体结构示例
```
ConfirmButton (Prefab)
├── Button (Component)
├── Image (Component)
└── Text (Component)
    └── "确认"

CancelButton (Prefab)
├── Button (Component)
├── Image (Component)
└── Text (Component)
    └── "取消"
```

## 布局系统

### 自动布局特性
- **水平排列**：按钮水平排列在对话框底部
- **居中对齐**：按钮在容器中居中对齐
- **自动间距**：按钮之间保持设定间距
- **统一大小**：所有按钮使用相同大小

### 布局参数
- `buttonSpacing`：按钮间距（像素）
- `buttonSize`：按钮大小（宽x高）
- `childAlignment`：子元素对齐方式（居中）
- `childControlWidth/Height`：控制子元素大小

## 调试功能

### Context Menu测试
- **测试退出游戏**：测试完整的退出流程
- **强制退出游戏**：直接退出不显示确认对话框
- **重新创建按钮**：清除并重新创建按钮

## 高级功能

### 动态按钮管理
```csharp

exitManager.RecreateButtons();

// 获取按钮引用
Button[] buttons = exitManager.GetButtonReferences();
Button confirmBtn = buttons[0];
Button cancelBtn = buttons[1];

// 清除现有按钮
exitManager.ClearExistingButtons();
```

### 自定义布局
```csharp
// 设置自定义布局参数

```

## 注意事项

1. **Canvas要求**：确认对话框必须在Canvas下，系统会自动查找
2. **预制体路径**：确保预制体路径正确，建议放在Resources文件夹
3. **按钮组件**：预制体必须包含Button组件
4. **布局冲突**：如果手动设置了按钮，请禁用自动布局
5. **性能考虑**：按钮在Start()时创建，避免在Update中重复创建

## 故障排除

### 常见问题

**问题1：按钮没有创建**
- 检查预制体引用是否正确设置
- 确认确认对话框在Canvas下
- 查看Console中的错误日志

**问题2：按钮布局不正确**
- 检查按钮大小设置是否合理
- 确认HorizontalLayoutGroup组件正常
- 尝试调整buttonSpacing参数

**问题3：按钮事件不响应**
- 确认预制体包含Button组件
- 检查按钮是否被其他UI元素遮挡
- 查看事件绑定日志

### 调试步骤
1. 启用调试日志（enableDebugLog = true）
2. 使用Context Menu测试功能
3. 检查Console中的详细日志
4. 使用"重新创建按钮"功能重置

## 扩展功能

### 添加更多按钮
可以通过修改CreateConfirmationButtons()方法来添加更多按钮类型。

### 自定义布局
可以修改CreateButtonContainer()方法来实现垂直布局或其他布局方式。

### 按钮样式
可以通过修改预制体来改变按钮的外观和样式。
