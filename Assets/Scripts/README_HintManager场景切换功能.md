# HintManager 场景类型功能使用说明

## 功能概述

HintManager现在支持根据场景类型显示不同的目标引用框，每个场景的HintManager在Inspector中预先设置好对应的场景类型。

## 场景类型

- **Level2**: 需要雨、孩、猎、王，以及日列表
- **Level3**: 需要叶、老、生

## 使用方法

### 在Inspector中设置

1. 选择包含HintManager组件的GameObject
2. 在Inspector中找到"场景设置"部分
3. 在"当前场景"下拉菜单中选择对应的场景类型：
   - 选择"Level2"会显示Level2场景的目标引用框
   - 选择"Level3"会显示Level3场景的目标引用框

### 目标引用设置

#### Level2场景目标引用
- **雨 (Rain)**: 雨对象引用
- **孩 (Child)**: 孩对象引用  
- **猎 (Hunter)**: 猎对象引用
- **王 (King)**: 王对象引用
- **日列表 (Sun Objects)**: 多个日对象的列表

#### Level3场景目标引用
- **叶 (Leaf)**: 叶对象引用
- **老 (Old)**: 老对象引用
- **生 (Life)**: 生对象引用

## 提示逻辑

不同场景会显示不同的提示文案：

### Level2场景提示
- "大雨拦路，想办法让雨「停」下吧"
- "孩童孤单，若能为他寻个「伙」伴……"
- "猎人终日巡守，让他稍作「休」息吧"
- "猛虎当道，恐怕需要一位「侠」士相助"
- "日轮高悬，凡人难及，或可化「仙」探寻"

### Level3场景提示
- "落叶飘零，寻找「叶」的归宿"
- "老者沉思，需要「老」的智慧"
- "生机盎然，感受「生」的力量"

## 注意事项

1. 确保为每个场景正确设置对应的目标对象引用
2. 每个场景的HintManager应该在Inspector中预先设置好正确的场景类型
3. 如果目标对象引用为空，对应的提示将不会显示
4. 场景类型设置后，提示逻辑会自动适配对应的场景类型

## 扩展说明

如需添加新的场景类型：

1. 在SceneType枚举中添加新的场景类型
2. 在HintManager中添加对应的目标引用字段
3. 在HintManagerEditor中添加对应的显示逻辑
4. 实现对应的提示逻辑方法（如GetLevel4HintCandidates等）

## 设计理念

- **每个场景独立**：每个场景都有自己的HintManager实例，在Inspector中预先配置
- **类型安全**：使用枚举确保场景类型的正确性
- **条件显示**：Inspector中只显示当前场景相关的目标引用框，避免混乱
- **易于维护**：清晰的代码结构，便于后续扩展和维护
